# Security

Report a listed mod that misbehaves, or a problem with this registry, through GitHub's private vulnerability reporting: https://github.com/HumanGenome/WaygateMods/security/advisories/new. There is no security mailing address; the form is the only channel. A confirmed report revokes the entry the same working day; every Waygate app removes the mod on its next start.

A problem in the code of one of the HumanGenome mods themselves can also go to https://github.com/HumanGenome/WaygateMods-first/security/advisories/new.
